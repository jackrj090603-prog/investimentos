módulo 1

O Motor de Valuation Modular (WACC, DCF e Monte Carlo)

Estruturado na pasta valuation/, o motor calcula o valor justo por ação de forma matemática robusta, cobrindo:

📉

Estimador do WACC

Baixa cotações históricas via yfinance, calcula o Beta de mercado da incorporadora frente ao Ibovespa por regressão OLS, aplica as fórmulas de Hamada para desalavancar e realavancar o Beta, e calcula o Custo de Capital Próprio ($K_e$) via CAPM.

🔮

DCF de Incorporação

Projeta o FCFF (Fluxo de Caixa Livre da Firma) em 5 anos. Usa um driver de lançamentos VGV ➔ VSO (Vendas) ➔ POC (reconhecimento por percentual de evolução de obra) ➔ Receita Operacional Líquida ➔ EBIT ➔ NOPAT (RET de 4.0%).

🎲

Monte Carlo (10k)

Sorteia 10.000 amostras a partir de distribuições triangulares de premissas (VSO, margem EBIT, g, Kd, Rf). Computa a média, desvio padrão, percentis P10, P50 (mediana), P90 e a probabilidade real de Upside.

módulo 2

O Agente de Monitoramento da CVM & RI

Localizado na pasta agente_cvm/, este serviço atua em paralelo monitorando relatórios oficiais e respondendo perguntas de investidores.

Arquitetura de Banco SQLite Local

Tabelas criadas: documentos (dedup de links de IPE da CVM e resumos executivos), estado (offset do bot de chat e timestamps), e conversas (RAG memória).

🔍 Raspagem Limpa (POST)
Acessa o WebService da CVM via POST payload, ignorando verificação de captcha quando vazio.
Lê linhas por &* e colunas por $&, extraindo o link do pop-up.
🧠 LLM Gemini (google-genai)
Utiliza o SDK google-genai. Extrai o conteúdo do link com scraping via URL.
Chama o modelo com baixo orçamento de pensamento (thinking budget) e com a Search Tool ativada.
📢 Telegram com Fallback
Envia alertas em formato HTML de alta legibilidade ao canal de avisos.
Se a IA quebrar tags HTML, intercepta o erro 400 e reenvia uma versão limpa automaticamente.
💻 Dashboard HTTP Nativo
Servidor nativo HTTP na porta 8000 com design dark premium e Outfit font.
Possui chip de pulsação e linhas colapsáveis para ler os resumos executivos da IA.

módulo 3

A Integração do StatusInvest & Planilhas do Mira

Garante que a sua planilha de valuation MONITOR DE VALUATION DO MIRA (3).xlsx receba dados do mercado em tempo real.

O que ocorre por baixo dos panos

O script faz uma requisição direta ao endpoint oculto de exportação do StatusInvest:

https://statusinvest.com.br/category/advancedsearchresultexport?CategoryType=1&search=...

Retorna um arquivo CSV contendo todas as 617 ações da bolsa brasileira. O script trata e converte as strings do padrão brasileiro (ex: "1.250,50" ou "1,25%") em floats numéricos, e reescreve a aba Dados Status Invest usando a biblioteca openpyxl.

módulo 5

Guia de Execução dos Sistemas

Os arquivos de inicialização rápida foram preparados para permitir o funcionamento imediato com 2 cliques.

1. Configurar Variáveis de Ambiente

Copie o arquivo .env.example para um novo arquivo .env na pasta agente_cvm/ e configure as chaves:

agente_cvm/.env 
GEMINI_API_KEY=sua_chave_do_google_ai_studio
TELEGRAM_BOT_TOKEN=seu_token_do_telegram_bot
TELEGRAM_CHAT_ID_ALERTAS=id_do_canal_de_alertas
TELEGRAM_CHAT_ID_CONVERSA=id_do_chat_privado_conversa

2. Executar no Windows (Dois Cliques)

Abra a pasta agente_cvm/ e execute o arquivo iniciar.bat. O script criará o ambiente virtual venv, instalará as bibliotecas e iniciará o robô de monitoramento e o painel.

3. Executar via Terminal Manual

terminal bash / powershell 
# 1. Entre no diretório do agente
cd agente_cvm/

# 2. Crie e ative o ambiente virtual
python -m venv venv
source venv/bin/activate  # venv\Scripts\activate no Windows

# 3. Instale as bibliotecas
pip install -r requirements.txt

# 4. Inicie o sistema unificado
python agente.py
📡
Ao iniciar o agente, o painel interativo ficará disponível em seu navegador pelo link: http://localhost:8000. As atualizações automáticas de fatos relevantes ocorrerão a cada 15 minutos.
